 


# Naleko Website

Corporate web application and lead-capture forms integrated with Salesforce.

## Project Structure
* `Web-Pages/` — Production HTML pages and landing templates
* `form-handler.js` — Client-side validation and Salesforce submission handler
* `.env.example` — Template for required Salesforce environment variables

## Local Setup
1. Clone the repository and switch to your working branch.
2. Copy `.env.example` to `.env` in the project root:
   ```bash
   cp .env.example .env
